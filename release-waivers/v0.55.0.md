# Release freshness waivers — v0.55.0

`make release-freshness-check` is path-granular: it asks whether a gallery
script or a perf-relevant path moved, not what moved inside it. Every item
it flagged for v0.55.0 is confined to Windows, which this release measures
on no machine — doppler's benchmarks and gallery art are produced on Linux.

Each line below waives exactly one item, and the gate prints it while
running, so a skipped check appears in the release log rather than
vanishing. A line that matches nothing stale fails the gate.

- gallery: src/doppler/examples/dsss_burst_pipeline_demo.py -- the change is
    a Windows-only early return in `wfmgen_available()` (doppler#1457);
    `make gallery` re-renders this script's PNG byte-identically, so there is
    nothing to commit and no stale picture to publish.
- benchmarks: native/inc/dp_complex.h -- the edit is entirely inside
    `#ifdef _WIN32`: it includes MSVC's `<complex.h>` first so numpy cannot
    re-declare the complex surface (doppler#1457). No Linux or macOS
    translation unit changes, so the published numbers still describe this
    tree.
- benchmarks: native/src/stream/CMakeLists.txt -- build gating only: the
    Python extension is skipped where `stream_core_obj` does not exist
    (Windows, doppler#1364). No kernel moved.
- benchmarks: native/src/wfm_sink/CMakeLists.txt -- generated by jm from
    `[module.wfm_sink] platforms`, which restricts the target to Linux and
    macOS. No kernel moved.
