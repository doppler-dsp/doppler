# Release freshness waivers — v0.75.0

`make release-freshness-check` counts a line as code unless it is an
unambiguous comment, so a changed C string literal (a docstring), a comment
continuation line, or module-import setup reads as code. v0.75.0 is a docs
release: every perf-relevant path below changed only in one of those ways,
or in a version constant or argument check outside any measured kernel. Each
was read line by line (`git diff -U0 v0.74.0.. -- <path>`, string literals
filtered out) before it was listed here.
