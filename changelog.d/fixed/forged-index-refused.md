- **A forged blob is refused, not written.** Objects whose `set_state` trusted an index now check it before the first write, and a refused blob returns `DP_ERR_INVALID` with that object unchanged (#2142, PR #2148). "Unchanged" covers the leaf only: a composition's child refusal is #2104, and RateConverter discarding a stage's refusal is #2138. `farrow`/`symsync` create refuses an order outside 0..2; wfm_synth `set_nsps`/`set_sym_pos` refuse an out-of-range value, and the Python methods raise `ValueError`.
