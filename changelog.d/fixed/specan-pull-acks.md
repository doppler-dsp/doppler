- **The specan `PullSource` acks every frame it reads (#2009).** It never acked, so the `doppler compose … specan` sink got every frame redelivered after AckWait. After 1000 pending frames it received only redeliveries, which it read as new data, and the frames stayed queued for the next run. A timeout now returns the buffered samples rather than raising: the bindings raise `TimeoutError`, while the old code checked for a `None` return. `pipeline_recv.py` acks too.
