- **CI runs on every push, and a run reports every red target.** A branch with no pull request now gets a minimal set (Linux 24.04 on x86 and arm, Windows, the floor and newest Python, lint, manifest drift, the sweep validators) instead of nothing until the PR opens; a push whose commit heads an open PR runs nothing, because the PR's run is the gate, and a newer push cancels the older run. After a job's build, its `make` steps no longer stop at the first red one. How a branch's state is read: `gh run list --branch <b> --limit 1 --json status,conclusion` ([CI](https://doppler-dsp.github.io/doppler/dev/ci/#a-push-without-a-pull-request)).
